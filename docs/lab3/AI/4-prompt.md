# Промпт 4. Кольори для alt та параметри дій

Зроби діаграму візуально кращою:
- Зроби підсвітку блоків `alt`: відмови/помилки підсвіти червоним (м'яким пастельним), а успіх — зеленим;
- Не пиши просто сигнатури функцій типу `reserveSeatHold(userId, tripId, seat)`. Напиши зрозумілим текстом дію, але в дужечках додай ті параметри, які реально передаються: `(seatNumber: 14)`, `(stations: [1..4])`, `(userId, status: HELD)`, `(price: 45000 коп)`, `(ticketId: UUIDv7)`;
- Додай тему `redux-color`.
