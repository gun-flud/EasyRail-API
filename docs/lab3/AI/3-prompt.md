# Промпт 3. Деталізація бронювання місця (Холд на 10 хв)

Давай тепер окремо розпишемо суто Фазу 2: Бронювання місця (Холд на 10 хв - ADR 006, 007, 008).

- Прибери всі емодзі, щоб виглядало нормально й академічно;
- Замість сирого SQL над стрілками напиши нормальні зрозумілі дії англійською (типу `Check active holds count`, `Lock overlapping segments`), щоб було видно суть кроку;
- У мене в Mermaid вибиває помилку `Trying to inactivate an inactive participant (DB)`. Виправ цей момент, щоб активація бази коректно відкривалася й закривалася через `+DB` та `-DB` і рендерилося без проблем.
