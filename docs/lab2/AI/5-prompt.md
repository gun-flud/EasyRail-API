# Промпт 5. Додавання нефункціональних вимог

## Мета

Доповни специфікацію `spec.md` нефункціональними вимогами на основі README проєкту EasyRail API.

## Що потрібно зробити

- Переглянь README та визнач нефункціональні вимоги, які в ньому прямо описані або чітко випливають із зазначених у ньому цілей системи.
- Додай їх після наявних функціональних вимог у відповідному розділі `spec.md`.
- Збережи стиль і термінологію документа. Якщо специфікація використовує ідентифікатори вимог, признач нефункціональним вимогам окремі, послідовні ID.
- Формулюй вимоги конкретно й перевірно настільки, наскільки це дозволяють вихідні матеріали.
- Не вигадуй числові межі, технології чи гарантії, яких немає в README. Якщо метрика або поріг потрібні, але не визначені, явно познач це як питання для уточнення.
- Перевір, що нові вимоги не дублюють і не суперечать функціональним вимогам у `spec.md`.

## Результат

Онови `spec.md`, додавши нефункціональні вимоги після функціональних. Коротко переліч їхні категорії та зазнач, якщо для повної перевірності бракує конкретних метрик у README.
